Pakai link MP3 yang bisa diakses publik.

Bernaung membutuhkan URL langsung menuju file audio, bukan halaman pemutar musik.

Format yang benar

Gunakan link yang benar-benar mengarah ke file MP3. Idealnya alamat berakhir dengan .mp3 atau server mengirim file audio secara langsung.

Cara umum

  1. Upload file MP3 ke layanan penyimpanan yang kamu gunakan.
  2. Atur akses menjadi dapat dibuka melalui link.
  3. Salin public/direct link file tersebut.
  4. Tempel link ke kolom Musik di Bernaung.
Link YouTube atau halaman preview layanan penyimpanan bukan direct MP3 link.
